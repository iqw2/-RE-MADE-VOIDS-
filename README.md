⌁ IP DEEP SEARCH

eine ip ist nicht einfach nur eine zahlenkombination dahinter können netzwerkbereiche provider asn informationen reverse dns einträge registrierungsdaten geografische zuordnungen und weitere öffentlich verfügbare metadaten stecken

VOID TOOLS versucht diese informationen an einem ort zusammenzuführen damit du ein besseres bild davon bekommst was öffentlich über eine adresse bekannt ist

⌁ URL DEEP SEARCH

eine domain ist mehr als nur ein name in der adressleiste

dns auflösung http response header tls informationen redirects security header und weitere öffentlich erreichbare hinweise können zeigen wie ein webauftritt technisch aufgebaut ist

keine oberflächlichen infos sondern ein strukturierter blick auf die daten die ein server freiwillig nach außen preisgibt

⌁ DNS & NETWORK INTELLIGENCE

reverse dns host resolution öffentliche ip informationen asn und rdap registrierungsdaten

finde heraus welche technischen informationen sich aus dns und öffentlichen registry quellen ableiten lassen und wie domains und ip adressen miteinander verbunden sind

⌁ WEB INTELLIGENCE

http header tls checks status codes redirect checks robots txt und security header analysen

hier geht es darum zu verstehen wie websites antworten welche sicherheitsrelevanten header vorhanden sind und welche konfigurationen öffentlich erkennbar sind

⌁ SECURITY ANALYSIS

email header analyzer hash tools base64 analyzer json inspector log analyzer und statische datei untersuchung
